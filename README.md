## 🧠 Sobre mim

Trabalho na ponte entre **inteligência artificial, dados e código**. Como **engenheiro de prompt**, desenho instruções, fluxos e agentes que fazem modelos de linguagem (LLMs) entregarem respostas confiáveis e úteis de verdade, e uso IA no dia a dia para acelerar o desenvolvimento, automatizar tarefas e resolver problemas de negócio.

Venho do suporte avançado (N2) em ERP, com foco em **análise de causa raiz, integridade de dados e sustentação de ambientes de produção**. Por isso conheço bem rotinas financeiras, estoque, regras fiscais brasileiras e bancos de dados relacionais. Hoje direciono essa bagagem para **desenvolvimento de software, IA aplicada e administração de bancos de dados (DBA)**.

## 🚀 No que eu trabalho

- 🤖 **Engenharia de prompt e IA aplicada:** criação e refinamento de prompts, instruções de sistema, fluxos com agentes e automações com LLMs.
- 🗄️ **Bancos de dados:** PostgreSQL (modelagem, consultas avançadas, views, triggers, PL/pgSQL, saneamento de dados, PgBouncer), Firebird e SQL Server.
- ⚙️ **Back-end e APIs:** APIs REST em Go (Gin), C# (.NET) e Python, integradas a bancos de dados e rodando em Docker.
- 🔁 **Automação:** fluxos web automatizados com Python e Playwright para testes funcionais e extração de dados.
- 🧾 **Domínio fiscal:** NF-e, NFC-e, NFS-e, MDF-e, GNRE, SPED, CFOP, CST/CSOSN e IBS/CBS.
